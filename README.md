# IO Analyzer

범용 산업연관분석 웹 애플리케이션의 초기 버전입니다.

## 현재 구현된 기능
- 대시보드 및 메뉴 화면
- Excel 파일(.xlsx, .xls, .xlsm) 업로드
- 업로드한 워크북의 시트 목록 표시
- 선택한 시트의 상위 30행 미리보기
- 산업분류 기준 선택 UI
- 브라우저 내 파일 처리

## 실행 및 배포
1. 저장소 최상위에 `index.html`, `css/`, `js/`, `.nojekyll` 파일을 둡니다.
2. GitHub 저장소의 Settings → Pages로 이동합니다.
3. Source를 `Deploy from a branch`로 선택합니다.
4. Branch는 `main`, Folder는 `/ (root)`로 설정하고 Save를 누릅니다.

## 데이터 및 개인정보
업로드한 파일은 브라우저에서 읽으며 별도 서버로 전송하지 않습니다. 단, 외부 CDN에서 Excel 라이브러리를 불러오기 때문에 웹사이트 이용 시 인터넷 연결이 필요합니다. 공개 저장소에는 공개 권한이 있는 자료만 포함하세요.

## 개발 상태
현재 버전은 데이터 업로드 및 구조 확인 단계입니다. 산업연관분석 계산 기능은 데이터 형식 검증 후 추가할 예정입니다.
